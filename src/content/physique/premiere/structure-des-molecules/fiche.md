<div class="encadre">

**L'image.** Chaque atome a un nombre fixe de mains (H 1, O 2, N 3, C 4). Une liaison entre atomes d'électronégativités différentes, c'est un tir à la corde déséquilibré.

</div>

## Lewis

- Duet (H), octet (C, N, O, Cl). Doublets liants = traits entre atomes, non liants = traits autour, lacune = rectangle.
- N : 3 liaisons + 1 doublet ; O : 2 liaisons + 2 doublets ; Cl : 1 liaison + 3 doublets.

## Géométrie

| Autour de l'atome central | Forme |
|---|---|
| 4 liaisons | tétraédrique (109,5°) |
| 3 liaisons + 1 doublet | pyramidale |
| 2 liaisons + 2 doublets | coudée |
| 2 doubles liaisons | linéaire |
| 1 double + 2 simples | plane triangulaire |

## Polarité

<div class="etape o">

Liaison polarisée si $\Delta\chi \gtrsim 0{,}4$ ($\delta^-$ sur le plus électronégatif). Molécule polaire si les centres des $\delta^+$ et $\delta^-$ ne coïncident pas.

</div>

## Les pièges

- <span class="p">$\mathrm{CO_2}$ et $\mathrm{CCl_4}$ : liaisons polarisées, molécules apolaires</span>.
- Les doublets non liants comptent pour la géométrie.
