titre: Énergie électrique
---

<div class="encadre">

**L'image.** La pompe d'une fontaine : débit = intensité, hauteur = tension, frottements = effet Joule, même dans la pompe.

</div>

## Les formules

- $I = Q/\Delta t$, $e = 1{,}6 \times 10^{-19}\ \mathrm{C}$.
- Pile réelle : $U_{PN} = E - rI$.
- $P = UI$, $\mathcal{E} = P\,\Delta t$, $1\ \mathrm{kWh} = 3{,}6 \times 10^{6}\ \mathrm{J}$.
- Effet Joule : $P_J = RI^2$.

<div class="etape o">

**Bilan.** $P_{\text{reçue}} = P_{\text{utile}} + P_{\text{perdue}}$, rendement $\eta = P_{\text{utile}}/P_{\text{reçue}} < 1$.
Pile : $EI = U_{PN}I + rI^2$.

</div>

## Les pièges

- <span class="p">kWh = énergie, W = puissance</span>.
- Les pertes sont presque toujours thermiques.
