## Sources

- Non renouvelables : pétrole, gaz, charbon, uranium.
- Renouvelables : Soleil, vent, eau, biomasse, géothermie.

## Formes et conversions

<div class="etape o">

Formes : thermique, électrique, lumineuse, de mouvement, chimique.
Éolienne : mouvement → électrique. Panneau solaire : lumineuse → électrique. Lampe : électrique → lumineuse.

</div>

- Chaîne d'énergie : source → convertisseur → usage. Pertes en chaleur.

## Les pièges

- <span class="p">L'électricité est une forme, pas une source</span>.
