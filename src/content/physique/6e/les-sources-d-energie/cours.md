## Le problème

Pour s'éclairer, se chauffer, se déplacer, recharger un téléphone, il faut de l'énergie. Mais d'où vient-elle ? Certaines sources seront épuisées un jour, d'autres non. Bien les connaître aide à mieux choisir.

## L'idée : le garde-manger et le potager

Imagine deux façons de se nourrir.

- Un **garde-manger** rempli il y a très longtemps. On se sert, mais personne ne le remplit plus. Un jour, il sera **vide**.
- Un **potager**. On récolte, et ça **repousse** chaque saison.

Le pétrole, le gaz et le charbon sont le garde-manger : ils se sont formés en des millions d'années. Le Soleil, le vent et l'eau qui coule sont le potager. <mark>Les sources renouvelables se reconstituent, les autres s'épuisent.</mark>

## Deux familles de sources

<div class="encadre">

| Sources **non renouvelables** | Sources **renouvelables** |
|---|---|
| pétrole | Soleil |
| gaz naturel | vent |
| charbon | eau qui coule (rivières, barrages, marées) |
| uranium (centrales nucléaires) | bois et déchets végétaux (biomasse) |
| | chaleur de la Terre (géothermie) |

</div>

Le pétrole, le gaz et le charbon sont des combustibles **fossiles** : en brûlant, ils rejettent du dioxyde de carbone, qui renforce l'effet de serre et réchauffe le climat.

## Les formes d'énergie

L'énergie peut prendre plusieurs formes :

- énergie **thermique** (la chaleur) ;
- énergie **électrique** ;
- énergie **lumineuse** ;
- énergie **de mouvement** (une éolienne qui tourne, une voiture qui roule) ;
- énergie **chimique** (stockée dans les aliments, l'essence, les piles).

## Convertir l'énergie

<div class="etape o">

Un **convertisseur** transforme une forme d'énergie en une autre.

- Une **éolienne** : énergie de mouvement du vent → énergie électrique.
- Un **panneau solaire** : énergie lumineuse → énergie électrique.
- Une **lampe** : énergie électrique → énergie lumineuse (et un peu de chaleur).
- Un **moteur électrique** : énergie électrique → énergie de mouvement.

</div>

On représente le trajet de l'énergie par une **chaîne d'énergie** : la source, puis les convertisseurs, puis l'usage. Exemple : vent → éolienne → électricité → lampe → lumière.

À chaque conversion, une partie de l'énergie est « perdue », le plus souvent en chaleur. Une ampoule à incandescence chauffe beaucoup, une LED beaucoup moins : elle gaspille moins.

## Économiser l'énergie

- Éteindre la lumière en quittant une pièce.
- Ne pas laisser les appareils en veille.
- Baisser un peu le chauffage et bien fermer les fenêtres.
- Préférer la marche, le vélo ou les transports en commun pour les petits trajets.

## Les pièges

- L'électricité est une **forme** d'énergie, pas une source.
- Le bois est renouvelable **si on replante** les arbres.
- Une centrale nucléaire utilise de l'uranium, une source **non renouvelable**.
- À chaque conversion, une partie de l'énergie part en **chaleur**.
