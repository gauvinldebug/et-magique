<div class="encadre">

**L'image.** Deux ombres : sur le sol, un mouvement uniforme ; sur le mur, une balle lancée verticalement. Ensemble, une parabole.

</div>

## Chute libre ($\vec{j}$ vers le haut)

<div class="etape o">

$\vec{a} = \vec{g}$. $\ v_x = v_0\cos\alpha$, $v_y = -gt + v_0\sin\alpha$. $\ x = v_0\cos\alpha\,t$, $y = -\frac{1}{2}gt^2 + v_0\sin\alpha\,t$.

</div>

- Trajectoire : $y = -\dfrac{g}{2v_0^2\cos^2\alpha}x^2 + \tan\alpha\,x$.
- Sommet : $v_y = 0$. Point de chute : $y = y_0$.
- $E_m = \frac{1}{2}mv^2 + mgy$ se conserve.

## Champ électrique

| Grandeur | Formule |
|---|---|
| champ entre plaques | $E = U/d$, de + vers − |
| force | $\vec{F} = q\vec{E}$ |
| accélération | $\vec{a} = q\vec{E}/m$ (poids négligé) |
| accélérateur | $\frac{1}{2}mv_B^2 - \frac{1}{2}mv_A^2 = qU_{AB}$ |

## Les pièges

- <span class="p">Au sommet, $v = v_0\cos\alpha \neq 0$</span>.
- Mouvement indépendant de la masse en chute libre.
- Signe de $a_y$ selon l'orientation de l'axe.
