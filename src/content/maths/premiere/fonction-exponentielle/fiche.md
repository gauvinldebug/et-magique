---
titre: Fonction exponentielle
---

<div class="encadre">

**L'image.** La pâte qui lève à une vitesse égale à sa taille : $\cbleu{f}' = \cbleu{f}$ et $\cbleu{f}(0) = 1$. Elle n'est jamais vide et ne fait que gonfler.

</div>

## Les règles

<div class="etape o">

$\mathrm{e}^{a + b} = \mathrm{e}^{a}\mathrm{e}^{b}$ ; $\mathrm{e}^{-a} = \frac{1}{\mathrm{e}^{a}}$ ; $\mathrm{e}^{a - b} = \frac{\mathrm{e}^{a}}{\mathrm{e}^{b}}$ ; $(\mathrm{e}^{a})^n = \mathrm{e}^{na}$.

</div>

- $\mathrm{e}^0 = 1$ ; $\mathrm{e}^1 = \mathrm{e} \approx 2{,}718$.
- $\mathrm{e}^{\corange{x}} > 0$ pour tout $\corange{x}$.

## Dériver

- $(\mathrm{e}^{\corange{x}})' = \mathrm{e}^{\corange{x}}$ ; $(\mathrm{e}^{k\corange{x}})' = k\mathrm{e}^{k\corange{x}}$ ; $(\mathrm{e}^{a\corange{x} + b})' = a\mathrm{e}^{a\corange{x} + b}$.
- Produit : $(\corange{x}\mathrm{e}^{\corange{x}})' = \mathrm{e}^{\corange{x}} + \corange{x}\mathrm{e}^{\corange{x}} = (1 + \corange{x})\mathrm{e}^{\corange{x}}$.

## Résoudre

- $\mathrm{e}^{A} = \mathrm{e}^{B} \iff A = B$ ; $\mathrm{e}^{A} < \mathrm{e}^{B} \iff A < B$.
- Pour le signe de $(\dots)\,\mathrm{e}^{\corange{x}}$ : l'exponentielle est positive, seul le facteur $(\dots)$ compte.
- $\mathrm{e}^{\corange{x}} = 0$ ou $\mathrm{e}^{\corange{x}} = -3$ : pas de solution.

## Suites

$u_{\corange{n}} = \mathrm{e}^{\corange{n}a}$ est géométrique de raison $\mathrm{e}^{a}$.

## Les pièges

- <span class="p">$\mathrm{e}^{a + b} \ne \mathrm{e}^{a} + \mathrm{e}^{b}$</span>.
- $\mathrm{e}^{2\corange{x}} = (\mathrm{e}^{\corange{x}})^2$, pas $2\mathrm{e}^{\corange{x}}$.
- Ne pas oublier le facteur $k$ en dérivant $\mathrm{e}^{k\corange{x}}$.
