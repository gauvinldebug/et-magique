<div class="encadre">

**L'image.** Une expression est un panier de fruits. Réduire, c'est ranger : les $\corange{x}$ avec les $\corange{x}$, les $\corange{x}^2$ avec les $\corange{x}^2$, les nombres avec les nombres. On ne mélange pas.

</div>

## Écritures

- $3 \times \corange{x} = 3\corange{x}$ ; $\corange{x} \times \corange{x} = \corange{x}^2$.
- Substituer : remplacer la lettre par une valeur.

## Réduire

- $5\corange{x} + 3 - 2\corange{x} + 7 = 3\corange{x} + 10$.
- $3\corange{x} + 2\corange{x}^2$ : on ne peut pas réduire.

## Développer

<div class="etape o">

| Règle | Exemple |
|---|---|
| $\cbleu{k}(a + b) = \cbleu{k}a + \cbleu{k}b$ | $4(\corange{x} + 2) = 4\corange{x} + 8$ |
| $(a + b)(c + d) = ac + ad + bc + bd$ | $(\corange{x} + 1)(\corange{x} + 5) = \corange{x}^2 + 6\corange{x} + 5$ |
| $-(a - b) = -a + b$ | $-(\corange{x} - 3) = -\corange{x} + 3$ |

</div>

## Prouver

- Un exemple ne prouve rien.
- Entier quelconque : $\corange{n}$ ; consécutifs : $\corange{n}$, $\corange{n} + 1$ ; pair : $2\corange{n}$ ; impair : $2\corange{n} + 1$.

## Les pièges

- <span class="p">Pas de pommes avec des poires</span>.
- $3\corange{x} \times 2\corange{x} = 6\corange{x}^2$, pas $6\corange{x}$.
- $(-\corange{x})^2 = \corange{x}^2$, mais $-\corange{x}^2$ est négatif.
