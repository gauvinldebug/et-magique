titre: Nombres relatifs

<div class="encadre">

**L'image.** Un ascenseur : 0 est le rez-de-chaussée, les étages sont positifs, les sous-sols négatifs. Ajouter, c'est monter ; soustraire, c'est descendre.

</div>

## Vocabulaire

- Opposés : $4$ et $-4$.
- Distance à zéro : le nombre sans son signe.
- Coordonnées $A(\text{abscisse}\,;\text{ordonnée})$ : horizontal d'abord.

## Comparer

- Négatif < positif.
- Entre négatifs : le plus loin de 0 est le plus petit. $-8 < -3$.

## Calculer

<div class="etape o">

| Cas | Règle | Exemple |
|---|---|---|
| même signe | on additionne, on garde le signe | $(-4) + (-3) = -7$ |
| signes contraires | on soustrait, signe du plus loin de 0 | $(-9) + 5 = -4$ |
| soustraction | on ajoute l'opposé | $5 - (-2) = 7$ |

</div>

## Les réflexes

- Écart entre deux températures : arrivée moins départ.
- Une soustraction devient toujours une addition.

## Les pièges

- <span class="p">$-8$ est plus petit que $-3$</span>.
- Moins un négatif, ça monte.
- Abscisse d'abord, ordonnée ensuite.
