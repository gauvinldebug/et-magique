<div class="encadre">

**L'image.** $i$ est un quart de tour. Deux quarts de tour font un demi-tour : $i^2 = -1$.

</div>

## Forme algébrique

- $\corange{z} = \cbleu{a} + i\cvert{b}$, $a = \text{Re}(z)$, $b = \text{Im}(z)$, unique.
- Égalité : mêmes parties réelles **et** imaginaires.
- Calcul : on développe, puis $i^2 = -1$.

## Conjugué

<div class="etape o">

| Propriété | Formule |
|---|---|
| définition | $\overline{a + ib} = a - ib$ |
| produit | $z\bar{z} = a^2 + b^2$ |
| somme, produit | $\overline{z + z'} = \bar{z} + \bar{z'}$, $\overline{zz'} = \bar{z}\bar{z'}$ |
| $z$ réel | $\bar{z} = z$ |
| $z$ imaginaire pur | $\bar{z} = -z$ |

</div>

## Quotient

- Multiplier en haut et en bas par le conjugué du dénominateur.

## Second degré (coefficients réels)

- $\Delta < 0$ : $\frac{-b \pm i\sqrt{-\Delta}}{2a}$, deux solutions conjuguées.

## Les pièges

- <span class="p">$i^2 = -1$</span> : $(3i)^2 = -9$.
- $\text{Im}(a + ib) = b$, pas $ib$.
- $\sqrt{-36}$ n'a pas de sens : on écrit $6i$.
