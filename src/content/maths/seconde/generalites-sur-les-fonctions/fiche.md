<div class="encadre">

**L'image.** Une fonction est une machine : on entre $\corange{x}$, il sort $\cbleu{f}(\corange{x})$. La courbe est le profil d'une randonnée : on monte (croissante), on descend (décroissante).

</div>

## Vocabulaire

- $\cbleu{f}(\corange{a}) = b$ : $b$ est **l'**image de $\corange{a}$, $\corange{a}$ est **un** antécédent de $b$.
- $D_f$ : les $\corange{x}$ autorisés (pas de division par 0, pas de racine d'un négatif).
- $M(x\,;y) \in \mathcal{C}_f \iff y = \cbleu{f}(x)$.

## Lecture graphique

<div class="etape o">

| Je cherche | Je lis sur |
|---|---|
| une image | l'axe des ordonnées |
| un antécédent | l'axe des abscisses |
| $\cbleu{f}(\corange{x}) = k$ | abscisses des points sur $y = k$ |
| $\cbleu{f}(\corange{x}) > k$ | abscisses des points au-dessus |

</div>

## Variations

- Croissante : $a < b \Rightarrow \cbleu{f}(a) \le \cbleu{f}(b)$ (l'ordre est conservé).
- Décroissante : $a < b \Rightarrow \cbleu{f}(a) \ge \cbleu{f}(b)$ (l'ordre est inversé).
- Maximum, minimum : la valeur **et** l'endroit où elle est atteinte.

## Signe

- Au-dessus de l'axe des abscisses : $\cbleu{f}(\corange{x}) > 0$.
- Les zéros de $\cbleu{f}$ : là où la courbe coupe l'axe.

## Les pièges

- <span class="p">Une image est unique, un antécédent non</span>.
- Le maximum est une valeur de $\cbleu{f}(\corange{x})$, pas de $\corange{x}$.
- Une solution graphique est une valeur approchée.
