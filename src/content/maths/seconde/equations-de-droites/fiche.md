titre: Équations de droites et systèmes
---

<div class="encadre">

**L'image.** Une droite est une route : on avance de 1, on monte de $\corange{m}$ (la pente). Deux routes qui se croisent forment un carrefour : la solution du système.

</div>

## Équations

<div class="etape o">

| Forme | Infos |
|---|---|
| $y = \corange{m}x + \cbleu{p}$ | pente $\corange{m}$, passe par $(0\,;\cbleu{p})$ |
| $x = c$ | droite verticale |
| $ax + by + c = 0$ | vecteur directeur $\begin{pmatrix} -b \\ a \end{pmatrix}$ |

</div>

- $\corange{m} = \frac{y_B - y_A}{x_B - x_A}$ ; vecteur directeur $\begin{pmatrix} 1 \\ \corange{m} \end{pmatrix}$.
- Trouver $\cbleu{p}$ : je remplace les coordonnées d'un point dans $y = \corange{m}x + \cbleu{p}$.

## Parallèles

- Même coefficient directeur $\iff$ parallèles.

## Systèmes

- Une solution si $ab' - a'b \ne 0$ (droites sécantes).
- Substitution : isoler, remplacer.
- Combinaison : multiplier les lignes pour éliminer une inconnue.

## Les réflexes

- Un point est sur la droite : ses coordonnées vérifient l'équation.
- Toujours vérifier la solution dans les **deux** équations.

## Les pièges

- <span class="p">Droite verticale : pas de $y = mx + p$</span>.
- $\corange{m}$ : différence des $y$ **sur** différence des $x$.
- Une équation cartésienne n'est pas unique (on peut tout multiplier par 2).
