---
titre: Ensembles de nombres
---

<div class="encadre">

**L'image.** Les ensembles sont des poupées russes : $\cvert{\mathbb{N}} \subset \corange{\mathbb{Z}} \subset \cbleu{\mathbb{D}} \subset \mathbb{Q} \subset \crouge{\mathbb{R}}$. Chaque poupée contient les plus petites.

</div>

## Les ensembles

- $\cvert{\mathbb{N}}$ : $0, 1, 2\dots$ ; $\corange{\mathbb{Z}}$ : on ajoute les négatifs ; $\cbleu{\mathbb{D}}$ : écriture décimale finie.
- $\mathbb{Q}$ : $\frac{a}{b}$, $b \ne 0$. $\frac{1}{3} \in \mathbb{Q}$ mais $\frac{1}{3} \notin \cbleu{\mathbb{D}}$.
- $\crouge{\mathbb{R}}$ : toute la droite. $\sqrt{2}$, $\pi$ sont irrationnels.

## Les intervalles

<div class="etape o">

| Écriture | Inégalité |
|---|---|
| $[a\,;b]$ | $a \le x \le b$ |
| $]a\,;b[$ | $a < x < b$ |
| $[a\,;+\infty[$ | $x \ge a$ |
| $]-\infty\,;b[$ | $x < b$ |

</div>

- $\cap$ : dans les deux ; $\cup$ : dans l'un ou l'autre.
- Valeur absolue : $|x - a|$ = distance entre $x$ et $a$, donc $|x - a| \le r \iff x \in [a - r\,;a + r]$.

## Puissances et racines

- $a^n a^p = a^{n+p}$ ; $\frac{a^n}{a^p} = a^{n-p}$ ; $(a^n)^p = a^{np}$ ; $a^{-n} = \frac{1}{a^n}$.
- $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ; $\sqrt{50} = 5\sqrt{2}$.

## Les pièges

- <span class="p">Crochet ouvert à l'infini, toujours</span>.
- $\sqrt{a + b} \ne \sqrt{a} + \sqrt{b}$.
- $(-2)^2 = 4$ mais $-2^2 = -4$.
