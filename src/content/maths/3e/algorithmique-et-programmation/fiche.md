**L'image.** Le lutin suit une partition : dans l'ordre, avec des refrains (boucles) et des variantes (conditions).

</div>

## L'essentiel

| Bloc | Rôle |
|---|---|
| mettre / ajouter à | variable |
| répéter n fois | boucle bornée |
| répéter jusqu'à | s'arrête quand la condition devient vraie |
| si … alors … sinon | condition |
| bloc personnalisé | réutiliser un morceau de code |

<div class="etape o">

Polygone régulier à $n$ côtés : répéter $n$ fois [avancer ; tourner de $\frac{360}{n}$].

</div>

## Les pièges

- <span class="p">Rotation de $\frac{360}{n}$, pas l'angle intérieur.</span>
