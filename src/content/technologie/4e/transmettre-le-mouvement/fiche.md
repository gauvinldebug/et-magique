<div class="encadre">

**L'image.** Les vitesses du vélo : grand pignon pour la force, petit pignon pour la vitesse.

</div>

## L'essentiel

$$r = \frac{Z_{\text{menante}}}{Z_{\text{menée}}} \qquad N_{\text{sortie}} = r \times N_{\text{entrée}}$$

| Système | Effet |
|---|---|
| engrenage | rotation, sens inversé |
| courroie, chaîne | rotation, même sens |
| pignon-crémaillère | rotation ↔ translation |
| bielle-manivelle | rotation ↔ va-et-vient |
| vis-écrou | rotation → translation |

## Les pièges

- <span class="p">Engrenage : sens inversé.</span>
- $r > 1$ : plus vite, moins de force.
