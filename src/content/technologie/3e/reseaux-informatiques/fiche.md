<div class="encadre">

**L'image.** Un quartier : les rues relient les maisons (commutateur), la poste envoie vers les autres villes (routeur).

</div>

## L'essentiel

| Élément | Rôle |
|---|---|
| commutateur | relie les machines d'un réseau local |
| routeur | relie des réseaux différents |
| box | routeur + commutateur + Wi-Fi |
| adresse IP | identifie une machine dans un réseau |
| adresse MAC | identifie la carte réseau, fixe |
| serveur / client | fournit / demande un service |

<div class="etape o">

Temps de transfert = taille (en bits) ÷ débit (en bit/s). 1 octet = 8 bits.

</div>

## Les pièges

- <span class="p">Mo (octets) et Mbit/s (bits) : facteur 8.</span>
- Commutateur et routeur n'ont pas le même rôle.
