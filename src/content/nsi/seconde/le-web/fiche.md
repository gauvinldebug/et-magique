<div class="encadre">

**L'image.** Une bibliothèque géante dont les livres sont reliés par des fils : tirer un fil, c'est cliquer sur un lien.

</div>

## L'essentiel

| Notion | Rôle |
|---|---|
| URL | adresse d'une ressource : protocole, domaine, chemin |
| HTML | contenu et structure (balises) |
| CSS | apparence de la page |
| HTTP | requête du client, réponse du serveur |
| HTTPS | HTTP chiffré |
| cookie | petit fichier déposé par un site |

<div class="etape o">

Moteur de recherche : explorer les liens, indexer les pages, classer les résultats.

</div>

## Les pièges

- <span class="p">Le cadenas HTTPS ne prouve pas qu'un site est fiable.</span>
- Le Web est un service d'Internet, pas Internet lui-même.
