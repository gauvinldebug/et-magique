## L'essentiel

| Notion | Rôle |
|---|---|
| adresse IP | identifie une machine (IPv4 : 4 nombres de 0 à 255) |
| paquet | morceau de données avec adresse de départ et d'arrivée |
| routeur | aiguille les paquets vers la suite du trajet |
| IP | adresser et acheminer les paquets |
| TCP | numéroter, vérifier, remettre dans l'ordre |
| DNS | traduire un nom de domaine en adresse IP |

<div class="etape o">

Pair à pair : chaque machine est à la fois cliente et serveur.

</div>

## Les pièges

- <span class="p">Internet est le réseau, le Web n'est qu'un service.</span>
- Les paquets d'un même fichier ne suivent pas forcément le même chemin.
