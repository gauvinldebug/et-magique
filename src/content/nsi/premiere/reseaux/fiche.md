## L'essentiel

<div class="etape o">

Données en paquets. IP : adresses et acheminement, sans garantie. TCP : numéros, accusés de réception, renvois, remise en ordre. DNS : nom → adresse IP.

</div>

`192.168.1.17/24` : 24 bits de réseau (192.168.1), 8 bits de machine.

Bit alterné : le bit du message alterne 0, 1, 0… ; sans accusé, on renvoie.

## Les pièges

- <span class="p">IP ne garantit rien, TCP fiabilise.</span>
- Routeur : entre réseaux. Commutateur : dans un réseau.
